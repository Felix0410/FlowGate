使用指南

从注册到调用

  1. 注册账号后登录，平台自动创建你的个人工作区。刷新页面需要重新登录。
  2. 进入“我的应用”填写标识和名称创建应用。
  3. 到“API市场”选择实际已上架的API，查看文档和免费单位，选择自己的应用领取。
  4. 免费权益每个用户对同一个API终身仅限一次，在领取所在的UTC自然月内有效。不同API独立计量。
  5. 回到“我的应用”签发短期调用凭证。Token有效期3600秒，只展示本次明文；离页即清除。增加API权益后可轮换凭证取得相应Scope，旧代次随即失效。
  6. 将API详情的curl示例中网关地址、路径变量和Token替换为你的实际值。在终端调用，不要把Token放进URL。
  7. 到“权益与用量”选择应用及API月份，查看实时余额和授权流水。RabbitMQ日报可能滞后；尚无统计不代表零使用量。

常见状态

401需要重新登录或使用正确用途的Token。跨账号对象统一404。403表示Scope、应用或权益不可用。429表示额度耗尽或登录限速。503表示依赖或功能开关不可用，请稍后重试。

每次成功授权即扣单位，下游失败不退还。Free5允许5次成功授权，第6次额度不足返回429。撤销凭证后，即使新签发开关关闭，旧代次仍不能再次获得授权。

市场没有商品时请联系平台运营。商品需在Console配置分类、商品、免费SKU并通过V12节点门禁后上架。

普通订单与模拟结算

API详情选择正价报价及自己的应用，确认订单后15分钟内模拟付款，不扣真钱。已付款待开通时请等待权益状态更新，已开通后到我的应用签发APP Token。下月权益下月UTC起才可调用。

未付款可取消；未履约或完全未使用可模拟退款，已有调用则拒绝退款，不回滚账本。已开通过的BASE槽保留，不能当月重购。

限时套餐与库存

Portal“限时套餐”选择自己的应用抢购。已受理只表示排队创单，订单就绪后模拟付款，再等待权益开通。每人每场限一次，同一应用/API/月与免费权益、普通订单互斥。取消或未付款超时释放预留，已付款退款不返售，已有授权流水不可退款。下月权益到固定UTC月份才生效。

Console“客户业务→API市场”读取活动与库存。管理员选择真实付费SKU创建、发布和暂停活动；发布后报价、月份和名额冻结。恢复时从数据库重建Redis，Poison消息保留检查；原SENT事件满300秒且未消费才可审计补投。缓存仅公开展示，交易以数据库核验为准。

最终候选与消息恢复

日常环境不会自动升级。D候选只在独立实例运行，本机使用 v12-d-preview.py start / doctor / stop 管理。付款均为模拟。

Console“客户业务→API市场→消息与业务消费”读取四条Rabbit链。SENT仅发送确认，Consumed是数据库消费；队列为空不代表业务成功，UNKNOWN表示依赖无法读取。促销重试8次耗尽显示RETRY_EXHAUSTED，管理员在事件和节点各满300秒、无租约且未消费时补投原事件，永久错误不自动解封。

Portal受理后等待订单，再模拟付款并确认权益开通。断网先查“我的抢购”，勿重复抢购；取消/超时释放未付款预留，退款不返售已售名额，已用权益不可退款。独立复审和负责人1280/375真人验收仍需分别确认。
