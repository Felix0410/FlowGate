FlowGate 管理后台：从接入到发布

产品入口：http://127.0.0.1:8081/console/ 。这份帮助也能从登录页和左侧底部离线打开。日常管理请使用新后台；旧 /test-console/ 只用于开发和故障验证。

1. 第一次登录：先看工作台

  1. 在IDEA启动Demo、Control、Gateway，Control和Gateway的环境文件指向项目根.env；数据库和Redis按现有配置运行。已运行时不要重复启动，也不要重置数据卷。更新代码后先Maven构建并重新启动Control。
  2. 打开产品入口，输入本机管理员账号与原始密码。不能用BCrypt哈希作密码；登录失败不会保留密码。
  3. 工作台显示真实目录数量、依赖健康和当前发布/节点版本。破折号表示没有读取到，不能理解成零。读取失败时点顶部“重新读取”。
  4. 首次无目录，先接入服务；已有目录，直接进入左侧对应列表编辑即可，不必重复创建Demo。

ADMIN可管理全部功能；OPERATOR可修改目录、规则和发布，不能签发/吊销调用方；VIEWER只读，写操作按钮禁用并说明原因。会话只在当前标签页内存，刷新或退出要重新登录。

2. 接入一个能调用的API

以现有Demo为例，只在没有同名对象时新建。示例不会自动替你创建数据。

  1. “服务管理 → 新建服务”：名称填“演示服务”，代码填demo，上游地址填http://127.0.0.1:8085，状态启用。这个地址必须已在部署白名单；换端口先联系部署负责人调整白名单。保存后看到“草稿已保存”。
  2. “API管理 → 新建API”：选择刚才服务，方法GET，入口/api/demo/fast/{id}，上游/demo/fast/{id}，权限公开，状态启用。大括号表示路径变量；不要写通配**。保存。
  3. “路由管理 → 新建路由”：名称demo-fast，选择刚才API，优先级0，状态启用。方法和路径自动沿用API。保存。
  4. 前往“发布中心”，发布全部草稿并确认。等待后点“重新读取”，确认当前Gateway为“已应用当前版本”。这时才可通过Gateway访问/api/demo/fast/123。

每张表都能搜索当前已读取列表，点“编辑”会回填全部字段。目录没有删除功能，需要停用时编辑状态；停用父服务/API之前，要同时停用相关启用路由和规则，否则发布会明确拒绝。

“草稿启用”只描述下次发布候选，不是已经上线。没有逐对象差异查询接口，因此列表不会编造“这条API已经应用”的标签。查看整体生效进度请到发布中心。

3. 给业务配置保护规则

先准备好服务/API/路由，再进入对应规则页点新建。选择保护对象类型和具体名称，不需要查数据库编号。

  • 速率限制：例如保护demo-slow，短时容量2、每秒补充1。超额返回429；多个Gateway共享同一Redis额度。容量是可积累的短时额度，每秒补充是持续速率。
  • 并发保护：例如demo-slow在途上限1。该网关已有一个未结束请求时，再来的请求返回503；每台网关单独计数，不是集群总并发。
  • 请求超时：例如demo-slow设200毫秒。调用耗时500毫秒时网关返回504。允许50–10000毫秒，网关结束不代表下游Servlet立即停止。
  • 熔断保护：选择一条路由，例如已存在的故障演示路由。失败率50%、窗口10次、最小样本5次、等待3000毫秒。达到阈值后短路503，等待后两次半开成功才能关闭；半开失败重新打开。静态不可用提示仅允许GET，仍返回503，不伪造成功。

点保存只是草稿，继续到发布中心发布并看节点版本。既有规则会显示后端真实绑定，编辑只能改参数、名称或启停，不能移动/删除已有目标；需要另一个目标时新建规则，并按需要停用旧规则。新建时若提示“规则已保存但绑定失败”，修正当前表单后再次保存即可，不会重新创建同名规则。

Caller范围的限速可选择本次登录签发的调用方。后端没有全量Caller列表，因此刷新后不能假装还能查询所有调用方；已有Caller规则仍可从真实绑定查看目标并修改参数。

频繁改变熔断参数会保留旧revision实例，当前适合低频本机演示，不承诺长期无限修改稳定。故障模拟和批量请求去底部开发工具，产品后台不运行压测或自动注入故障。

4. 发布与回滚：分清三个阶段

  1. 草稿已保存：数据库中的候选已修改，当前网关配置尚未因此改变。
  2. 配置已持久化：发布成功得到新版本，如V6；当前页面不能据此宣布全部网关应用。
  3. 节点已应用：最近上报心跳ONLINE，且该节点应用版本等于当前发布版本。历史节点心跳过期时应结合节点名称辨认当前实例。

发布会提交完整当前草稿，不只本页对象。确认框显示当前版本和下一版本；后台没有差异预览API，不会虚构新增数量。遇409，关闭确认框，重新读取版本和草稿，核对后再确认；页面绝不自动覆盖重试。

“回滚”以历史配置创建更大的新版本，确认框会说明来源和目标，不倒退版本号、不修改历史，也不覆盖草稿。历史“查看摘要”只展示版本/时间/checksum，不提供逐对象快照编辑。回滚后仍需等待节点应用。

5. 给私有API签发与撤销凭证

  1. 管理员进入“调用方管理”，填写名称和授权范围，例如demo:read，确认签发。
  2. 页面只在签发后给出一次性Token和编号，默认遮罩。显示后安全交付给调用方，记下回执编号。离开该页、清空、刷新或退出均清除Token，不能从历史找回。
  3. 私有API的所需范围必须包含在该调用方的授权范围中；无有效凭证401，缺少范围403。
  4. 需要撤销时输入回执中的调用方编号并二次确认。吊销立即失效，不需要发布。不要猜测编号；后端暂无全量查询列表，页面仅显示本次登录签发记录。

管理员登录Token和调用方Token用途不同，不能互换。请勿把凭证放在URL、截图或公开问题报告中。

6. 看懂运行监控和审计

运行监控显示真实节点版本、心跳和最近熔断摘要。未取得/空摘要不等于CLOSED；Control或Gateway重启后运行摘要可能重置。节点已过期时旧摘要也可能过期，不能当作实时状态。

基础指标从本机Gateway默认8080的只读Actuator读取。没有业务调用时某些指标不存在，显示暂无样本；端口不同或Gateway未启动也可能无法读取。不要为了让图表有数而改写状态。

操作审计每次读取最近50条，可继续加载更早记录；只读，记录配置、发布与身份管理动作。用户和请求的秘密不会作为正常页面的技术响应展示。

8. V1.1-A：客户 → 应用 → 套餐 → 订阅

本节介绍客户、应用、套餐和订阅管理，只有ADMIN可修改，OPERATOR和VIEWER只读。B新增凭证与计量的完整路线见下一节。原服务/API/路由与旧Caller保持V1行为，不需要为管理记录发布路由。

首次使用新增页面前，需在你选定的FlowGate数据库执行一次增量sql/flowgate-v11.sql。当前文件包含A五张与B五张新增表，重复执行不覆盖旧数据；启动应用不会自动迁移。本轮Codex只验证了独占临时数据库，没有修改你已有的持久化数据库。请确认目标库并完成备份后，由负责人执行。使用本项目现有Compose时，可在根目录运行：

source .env
docker compose -f compose.local.yml exec -T mysql sh -c 'MYSQL_PWD="$MYSQL_PASSWORD" mysql -u "$MYSQL_USER" "$MYSQL_DATABASE"' < sql/flowgate-v11.sql
mvn -B -ntp -pl flowgate-control -am package -DskipTests

然后在IDEA重新启动Control，刷新/console/，无需添加新的密码、Kafka或新服务。若采用自建MySQL，请在对应FlowGate库执行相同增量文件，不要误选其他项目数据库。不要重新执行初始化来清空已有数据。

  1. “客户与应用 → 客户管理 → 新建客户”：例如代码customer-a、名称“客户甲”、状态启用。代码只用字母、数字、横线、下划线，且在同类记录中唯一。
  2. “应用管理 → 新建应用”：按名称选择客户，代码app-a、名称“查询应用”、启用。客户暂停时不能新建应用。应用归属创建后固定；修改名称或暂停/恢复应用使用编辑，不删除订阅或旧记录。
  3. “套餐与订阅 → 套餐管理 → 新建套餐”：例如Free每月5单位、Pro每月20单位。这里是每月准入单位的套餐定义，不是余额、收费或已发放额度。额度范围1–1000000，创建后不可修改；编辑只改名称和启停，调整额度应新建套餐。
  4. “订阅记录 → 新建订阅”：按名称选择应用、套餐，填写UTC生效与到期时间。示例当前月2026-11-01T00:00:00Z到2026-12-01T00:00:00Z；日期按实际当前月调整，表单会提供当前UTC月份初值，后端以数据库UTC时间复验。日期以Z结尾，最多毫秒精度，受当前MySQL TIMESTAMP范围限制（2038年前）。
  5. 下月变更必须恰好在下一UTC自然月首日00:00开始。例如上述当前订阅到期后，可排队2026-12-01T00:00:00Z到2027-01-01T00:00:00Z。区间左闭右开，相邻端点不算重叠；最多一条当前和一条次月排队。并发创建重叠订阅会返回409，不会自动覆盖原订阅。
  6. “按客户查看应用”“按应用查看订阅”可筛选真实列表；每次20条，点“读取下一页”继续。关联名称选项每批100条，较多时点“继续读取选项”，无需手填数据库编号。
  7. 应用页“管理凭证”读取真实状态；默认关闭时提示尚未启用，签发API仍409 FEATURE_NOT_READY。部署负责人完成B迁移、全部网关升级并显式激活后才允许签发；不能通过刷新、改密码或换套餐绕过门禁。具体签发/轮换/撤销及计量抽查按下一节操作。原“调用方管理”的旧V1 Token用途不变。

订阅的“当前期间/待生效/已到期”按数据库UTC时钟派生；“关联主体/套餐暂停”单独说明父状态。它们只描述管理定义，不是已扣额度或成功计费。客户、应用或套餐停用后不能创建新的可用订阅，历史仍保留。当前版本不开放订阅区间编辑或状态PATCH，避免绕过互斥。

遇到503且旧页面正常，先确认所需新增表已在正确数据库迁移；代码重复409应编辑原记录或换代码；日期400应核对Z、月份首日和起止顺序；权限403应使用ADMIN。新管理记录保存立即持久化，不要反复点击V1发布中心来尝试绕过计量部署开关和节点能力门禁。

V11-B：从客户到计量账本的完整操作

本节只适用于已经部署B增量SQL和完整B版本的环境。默认关闭计量激活，普通V1业务继续沿用原Caller。请先在“发布中心”查看实际开关、完整接流节点名单及每个节点的“支持月度计量”；任何未知、过期或版本不一致都应先处理，不要反复点击签发或发布。部署配置见README，不能靠页面绕过门禁。

  1. ADMIN登录“客户管理”，新建启用客户；到“应用管理”选择该客户创建应用。OPERATOR/VIEWER只读这些业务记录。
  2. “套餐管理”创建Free，月度准入单位设为5。额度创建后不可修改，需要其他额度就新建套餐。套餐定义不是已经发放的余额。
  3. “订阅记录”选择应用、Free和“本月”。时间按UTC月份生成，数据库最终复验。同一应用同一UTC月只能选一次套餐，即使上条已到期也不能换套餐；下一月选择“下月首日”。高级模式可输入ISO8601 Z结尾的单月区间，结束端点不包含在区间内。
  4. “应用管理 → 管理凭证”读取真实状态。首次签发输入API所需Scope（例如demo:read），确认后在列表上方领取一次性应用Token。Token以fgapp_开头，仅驻留当前页面；支持显示/隐藏和复制，离页/退出/清空后不能找回。签发成功并不等于路由已发布。需要更换时重新输入完整Scope并“轮换凭证”，旧Token失效；“撤销凭证”立即阻断旧代次，失败提示时不要假设旧Token仍可用。
  5. “API管理”建立启用的私有API，填写同样的requiredScope并建立路由。“计量规则”新建月度计量准入，目标选择该API或路由，每次消耗1单位。一个实际路由只允许一个生效Quota；不能用于公开API，也不能绑定到Global/Service/Caller。
  6. “发布中心”核对全部草稿后发布，等完整接流名单的网关均确认当前版本。计量开关默认OFF；只有部署负责人在完整验证后显式启用并配置接流名单才能发布计量版本。回滚到含Quota历史同样受门禁约束。
  7. 使用HTTP客户端请求网关的该私有路径，设置Authorization: Bearer 加本次应用Token。不要使用管理员Token或旧CallerToken。Free5、每次1单位，前5次获准，第6次429 QUOTA_EXHAUSTED；其他限流、并发或熔断若先拒绝，请先处理这些保护条件再抽查额度。
  8. “配额与账本”选择应用和UTC月份（YYYYMM），点击查询余额与流水，必要时“读取下一页流水”。首次Grant才冻结总额、套餐版本及余额；没有余额行显示“尚无余额记录”，不是0。流水记录的是准入授权，不能当作业务成功统计；下游500、超时或取消仍消耗Grant，不退款。

错误处理：401检查Token格式、有效期和是否用对身份域；403检查客户/应用启停、当前订阅、Scope和凭证代次；429 QUOTA_EXHAUSTED表示本月额度耗尽，不能通过重新订阅换套餐绕开；503 QUOTA_UNAVAILABLE表示依赖不可达、在途已满或授权结果不确定，先查账本，不假设未扣。内部重试使用同chargeId幂等，浏览器重新发送业务请求是新的尝试，可能产生新消耗。

余额以MySQL为权威，Redis只服务会话及既有速率限制。仅部署B或未开启异步时，Outbox保持待投递；部署C并显式开启后按下一节查看真实投递与聚合状态。负责人仍须在真实浏览器1280px、375px及键盘操作中抽查表单、凭证领取、分页和错误提示；Node模拟DOM通过不能替代这项验收。

10. V11-B复审小修：旧月份检查与紧急撤销

计量开启之前，由部署负责人在已备份且明确的目标MySQL数据库中、使用只读权限执行sql/v11-b-upgrade-preflight.sql。它检查同应用同月多段订阅、跨月旧订阅及冻结余额定义不一致，四种风险计数必须确认均为0；脚本不会自动修改历史数据。发现非零时应停止启用计量，保留Ledger和余额并人工核对，不能删除旧订阅或重置月度额度来消除告警。此操作尚未在用户现有数据库执行。

如果历史数据中存在同月多条订阅，或者当前套餐与月度余额冻结的订阅ID、套餐ID、版本、额度不一致，新配额授权将被Control拒绝，内部业务码为QUOTA_SUBSCRIPTION_MISMATCH；Gateway可能统一显示依赖授权失败503，此时检查Control错误码和只读预检，不要将503误判成已成功扣量，也不要手工修改账本以绕过校验。

紧急撤销：即使FLOWGATE_QUOTA_ACTIVATION_ENABLED=false，先前签发的应用凭证仍可以由ADMIN在“应用管理→管理凭证”查看实际状态并点击“撤销凭证”。这项操作推进MySQL凭证代次、停用旧凭证；签发和轮换仍需激活完整配额链路和节点能力，不会因撤销入口开放而绕过。停用期间余额服务本来就失败关闭；若Redis清理失败，数据库代次仍阻止旧Token在恢复后使用。OPERATOR和VIEWER不能撤销。

实现与测试区别：上述小修Java、前端、JUnit、Node和隔离HTTP测试脚本已经提交，真实Java17/MySQL/Redis补测尚待V11-C的C0门槛；不能把“代码已修”当成“正式库已迁移、浏览器已验收”。

V11-C：异步用量、失败事件与封账对账

先完成B部署。C只在Control增加Kafka异步处理，不改变Gateway扣额链路。部署负责人在正确目标库执行sql/flowgate-v11-c.sql新增两张读模型表，重启新版Control；默认FLOWGATE_ASYNC_ENABLED=false，不启动Kafka也能继续B配额业务，Outbox会积压。单机演示可运行docker compose -f compose.local.yml --profile mq up -d kafka，然后为Control设置FLOWGATE_ASYNC_ENABLED=true和FLOWGATE_KAFKA_BOOTSTRAP_SERVERS=127.0.0.1:19092再重启。Gateway不配置Kafka。不要将单Broker演示当作生产高可用。

  1. “用量统计”：按应用名称、API和UTC日期查询，最多31天。显示每日授权单位、准入次数及最后聚合时间；这不是成功响应次数，也不是收费金额。没有记录时可能尚未调用、异步关闭或消费延迟，不能理解为消费为0。“读取下一页”使用完整日/应用/API游标，同一天多应用也不会漏页。
  2. “异步事件”：查看实际开关、Broker探测状态及检查时间、NEW/LEASED/SENT/FAILED数量和未消费数。NEW待投递；LEASED正在有界发送；SENT仅表示Broker确认，不代表已统计；FAILED需要诊断。事件列表不提供原始payload、用户Header或Token。
  3. FAILED处理：ADMIN先核对错误码、Broker/数据库状态，点击该事件“重投”并二次确认。它只将原事件重新排队，保留原eventId，不再扣额度；两个管理员同时点仅一人成功，另一人409后重新读取。OPERATOR/VIEWER可读，不可重投。
  4. “对账中心”：选择昨天及更早的UTC封账日，最多31天。比较权威Ledger授权单位/次数、已消费单位/次数和Daily聚合值。PENDING表示仍有事件未消费，先排查异步关闭、Broker故障、租约、FAILED或暂停分区；追平后应MATCH。MISMATCH表示事件已消费齐全但读模型不同，需负责人诊断；页面不自动改余额、流水或日表。
  5. Kafka停机：MySQL有效且额度足够时，B授权继续成功并积压Outbox；恢复后逐步投递、幂等汇总。不要反复发送业务请求来“修统计”，每次新业务尝试可能再次消耗额度。消费重复不会再次加总；重投、重启也不会生成新Grant。
  6. 毒消息/消费数据库故障：首版暂停问题分区并保留原offset，不发送没有ACK保证的DLT。查看进程计数与待消费数；确认修复数据/依赖后重启Control消费者，继续原offset。暂停期间其他分区可继续；不要自行跳过offset或删除Outbox/ConsumedEvent。进程计数重启归零，不是持久账本。

若API读取失败，页面显示状态未知，不用旧数或0冒充当前数据。Broker状态是带检查时间的短缓存真实探测，SENT、consumer lag、节点健康都不能单独证明对账一致。用量与对账日归属按Outbox不可变UTC事件时间，不能用Ledger插入日期替代。负责人仍需在1280px/375px和键盘操作中验收这三页；自动测试不能代替。
