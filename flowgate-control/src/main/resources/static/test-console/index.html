故障保护

先决定是等待多久（超时），还是连续故障时暂时停止访问（熔断）。 本页详细说明与填写示例

本页怎么用：先做什么、再点哪里
  1. 超时：demo-slow、200毫秒 → 保存、发布、确认节点 → 请求500ms应504。
  2. 熔断演示先给Demo开启故障开关，再添加故障API草稿并发布；选择demo-fault配置规则。
  3. 500等失败达到阈值后OPEN；停止故障、等半开、发两次正常请求并查询状态。GET静态不可用提示仍为503。

为 API 设置响应超时与故障熔断。保存只修改草稿；发布并确认节点应用后生效。

故障演示需本机 Demo 显式配置 FLOWGATE_DEMO_FAULT_ENABLED=true 并重启；默认关闭，原业务接口不受影响。

熔断状态来自节点最近上报；节点重启后运行状态可能已重置，STALE表示上报已过期。

尚未取得实际状态；不会根据请求次数推测熔断状态。

抽查演示：响应与恢复

504：等待超时；CIRCUIT_OPEN 503：当前禁止访问下游；DEGRADED 503：明确的不可用提示。恢复后发起两次正常请求，并刷新实际状态。认证、限流拒绝不会变为降级成功。
