抽查演示：响应与恢复

504：等待超时；CIRCUIT_OPEN 503：当前禁止访问下游；DEGRADED 503：明确的不可用提示。恢复后发起两次正常请求，并刷新实际状态。认证、限流拒绝不会变为降级成功。

帮助与使用指南

启动依赖：docker compose -f compose.local.yml up -d。IDEA 三个主类均用 JDK17；Control/Gateway 加载 FlowGate 根目录 .env。8085/8081/8080 端口占用时先停止旧进程。

使用路径：环境检查 → 登录 → 初始化公共 Demo → 读取当前版本 → 发布新版本 → 查询节点，确认 appliedVersion 等于发布版本 → 业务测试。回滚会生成更大新版本，不撤销草稿。

400 输入错误；401 凭证缺失/过期；403 权限不足；404 路由未发布；409 版本变化，请刷新版本并检查草稿；429 限速；503 并发满或依赖不可用。异常时查看响应 code 区分原因。

限速跨网关共享；在途并发仅限制单个网关。前层令牌扣减后，后层拒绝或并发拒绝不会退还。历史待执行策略不会自动激活。
